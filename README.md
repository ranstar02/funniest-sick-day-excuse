One line, under 200 characters: the funniest excuse someone could send to
call in sick from work — half believable, fully ridiculous, and landing in a
single breath.

This is an entry by RanSTAR ID for make.fun's
["The Funniest Sick-Day Excuse"](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36?ref=0m7x29es)
bounty ($2 in USDC).

## Run it

```sh
python3 main.py
```

It writes a single line to `/output/entry.txt` — nothing else.

## How it works

`main.py` has no dependencies and uses no network. It holds one
hand-written excuse, checks it is a single line of 1–200 characters, and
writes it out. Run it twice and you get the exact same file.
